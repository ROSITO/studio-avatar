# Support

Read the README and check engine paths, FFmpeg availability, model files, and the
VoiceStudio API before opening an issue. The interface currently uses French labels.

- Usage, installation, or workflow questions: [Discussions](https://github.com/ROSITO/studio-avatar/discussions).
- Reproducible software bugs: [bug report form](https://github.com/ROSITO/studio-avatar/issues/new/choose).
- Vulnerabilities: private reporting in [SECURITY.md](SECURITY.md).
- Conduct violations: reporting channels in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Support is community-based, with no guaranteed turnaround. Share the OS, Python
version, affected engine versions, and sanitized reproduction steps. Remove local
usernames, filenames, private prompts, tokens, portraits, voices, and recordings
from logs and screenshots before posting them.
