Chaque TAG ouvre un bloc : toutes les phrases qui suivent partagent le même mini-clip jusqu’au prochain TAG.

Tout est bon ?

Un TAG = un bloc, même s’il contient plusieurs phrases. Créez le projet, puis générez et ajustez ses clips dans la timeline. Les transitions LTX relient directement les poses des clips voisins.

Mes projets

Une timeline par projet. Chaque TAG possède son mini-clip ; chaque liaison se génère entre deux clips.

Modèles

Installez les poids compatibles et choisissez ceux utilisés pour vos prochaines générations. Les clips existants sont conservés.

Les moteurs LTX et MuseTalk doivent être installés séparément. Les poids se téléchargent depuis leurs dépôts d’origine ; consultez leurs licences dans les liens Sources. Les accès restreints nécessitent HF_TOKEN et une autorisation obtenue sur Hugging Face.

Importer un pack vidéo déjà installé

Mes avatars

Ajoute une photo (assise, de face, bouche fermée, mains visibles) : le Mac lui prépare tout seul un geste par situation (neutre, curieux, enthousiaste, réfléchi, sérieux, chaleureux), leurs transitions et un clip de repos, une fois pour toutes (≈ 1 h 20). Ensuite, chaque vidéo de cet avatar est rapide.
